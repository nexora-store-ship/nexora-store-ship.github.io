# NEXORA Store — Starter Website

This is the first working storefront prototype for NEXORA.

Included:
- Responsive homepage
- Global marketplace layout
- Search
- Category filtering
- Product cards
- Shopping cart
- Demo checkout flow
- Shipping statement excluding Syria
- Basic footer/policy navigation placeholders

IMPORTANT:
This prototype does NOT process real payments and does NOT place real supplier orders.
Before launch, connect:
1. A legally established business/payment setup.
2. PayPal Business or another supported payment provider.
3. A domain and hosting.
4. Real supplier integrations.
5. Final legal policies, taxes, shipping, returns and privacy terms.

To preview:
Open index.html in a browser.

Next build phase:

- Add real product images.
- Add product detail pages.

- Add analytics and SEO.
